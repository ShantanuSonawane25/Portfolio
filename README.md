**Technologies:** React, Vite, JavaScript, Node.js, Supabase, PostgreSQL, FFmpeg

**Key Features:**
- User authentication and profiles
- Music library, playlists, and liked songs
- Music search and playback
- Audio upload and metadata processing
- Artist-oriented music discovery and catalog management

### 2. Fake Product Review Detector

An AI/ML-based project focused on identifying potentially fake product reviews using natural language processing and machine learning.

**Technologies:** Python, Scikit-learn, TF-IDF, Flask, React, Docker

**Key Concepts:**
- Text preprocessing and feature extraction
- TF-IDF vectorization
- Machine learning-based text classification
- Backend API integration

*Status: In Development*

### 3. Document Q&A Assistant Using RAG

A document question-answering application that uses Retrieval-Augmented Generation concepts to retrieve relevant information from documents and provide context-based answers.

**Technologies:** Python, FAISS, Embeddings, Flask, React

**Key Concepts:**
- Document processing and text chunking
- Embedding generation
- Vector similarity search
- Top-k document retrieval
- Source passage references

*Status: In Development*

## Run Locally

You can run this portfolio on your local machine.

1. Clone the repository:

   ```bash
   git clone https://github.com/ShantanuSonawane25/Portfolio.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
